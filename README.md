# SkillUp Campus - Workspace Oficial

Plataforma web EdTech para la gestion centralizada de alumnos, catalogo de cursos e inscripciones.

## Estructura
- /backend: API REST con Node.js, Express, Prisma y PostgreSQL (Supabase).
- /frontend: Aplicacion web en React + Vite.
- /docs: Contratos de API (Postman), minutas de PM y reportes de QA.
- /product_y_growth: Entregables de Diseno, Marketing y Data.
